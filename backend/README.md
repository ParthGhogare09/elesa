# PlacePro Evaluate — Backend API

Production Express.js & MongoDB REST API for managing candidate evaluation workflows, 4 GD panels, groups, rubrics, qualification decisions, HR interview assessments, and composite leaderboards.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Seed database with 100 students, 4 panels, groups, and scoring
npm run seed

# 3. Start development server with file watching
npm run dev
```
